# WatermarkForge — Model Card

> 作者：晨星 · 版本 v0.1.0 · 纯 NumPy 研究型基准系统（非生产级服务）。

## 1. 模型细节

| 项 | 值 |
|----|-----|
| 类型 | LLM 文本水印（生成期加注 + 检测期判别） |
| 方案 | `kgw`（绿名单）· `gumbel`（失真无关）· `wmfuse`（双通道，消融） |
| 词表 | 合成基准 vocab_size=2000 |
| 失真预算 | equal-distortion，target_kl=0.3 nats/token |
| 标定强度 | kgw δ=1.8696 · gumbel β=0.4525 · wmfuse β=0.320/δ=1.318 |
| 检测 | 多尺度滑动窗口（8/16/32）联合 z 分数，null 方差标准化 |

## 2. 预期用途（Intended Use）

- 研究：在**受控同等失真**下比较水印方案对通道感知攻击的鲁棒性。
- 教学：失真无关水印、绿名单水印、等分位失真标定的可运行参考实现。
- 基线：作为新方案的对标基准（复现 `cli.py demo` 即出对照表）。

## 3. 超出范围（Out-of-Scope）

- 真实 LLM 集成（本系统用合成生成器，未接 HF/在线模型）。
- 长文本（>200 token）统计特性的外推。
- 作为版权/溯源的司法级证据（仅研究结论）。

## 4. 性能（来自 `benchmark.json`，真实运行）

旗舰 = **`gumbel` + 多尺度联合检测**。9/9 验收门禁全绿。

| 场景 | kgw | gumbel(旗舰) | wmfuse(消融) | 结论 |
|------|-----|--------------|--------------|------|
| 干净 L≥100 TPR@1%FPR | 1.00 | 1.00 | 0.97~1.00 | 干净均可检 |
| green_targeted@0.7,L200 | 0.05 | **0.83** | 0.11 | 旗舰胜 KGW +0.78 |
| contiguous@0.5,L200 | 1.00 | 0.98 | 0.75 | 旗舰匹配 KGW |
| gumbel_targeted@0.7,L200 | 1.00 | 0.12 | 0.06 | KGW 胜（绿名单方案对 Gumbel 攻击免疫） |

**诚实结论**：绿名单方案（KGW）在「攻击者知道绿名单」时崩溃（TPR→0.05），而失真无关 Gumbel 在同等预算下保持可检；反之 Gumbel 通道被针对性攻击时 KGW 更稳。**不存在单方案全场景必胜**，本系统如实呈现 trade-off，不虚构「世界最佳」。

## 5. 局限与风险

- 合成生成器无法完全刻画真实 LLM 的长程依赖与分布偏移。
- `wmfuse` 双通道在等分位预算下被稀释，证明「多通道叠加 ≠ 更鲁棒」，仅作反例。
- 攻击模型假设攻击者掌握密钥（最坏情形），真实部署应配合密钥轮换/不可链接性。

## 6. 伦理

水印用于**负责任溯源**；本系统不提供规避真实水印的工具，攻击模块仅用于鲁棒性度量。
